# Starfall on the Reaping
![Game Thumbnail]("thumbnail.png")

## Inspiration
Starfall on the Reaping is inspired by The Hunger Games franchise. It aims to recreate both the experience of fighting in the arena itself and the experience of viewing as a rich citizen of The Capitol.

## What it does
The kids are able to fight it out in the Roblox arena until only one remains as the victor. At the same time, parents can enjoy a drink while connecting to the companion website to view the status of each child and send gifts to their favorite (or the one they bet on). It's fun for the whole family!

## How we built it
The game itself is built in Roblox. It uses Roblox's HttpService to make POST and GET calls to the companion website.
